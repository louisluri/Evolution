# Evolution

My first programming project, each new version of neebler (1-5) is just when i decided to log the old version and make a major change that would make the simulation fundementally dffrent.

Each simulation just uses logic to make the creatures interact with eachother and their environment, then at the end of each episode they die or reproduce. And the new creatures are copys of their parents that can be slightly mutated.

"neuroevolution.py" Takes a completely diffrent approach, the creatures physical traits are the same. But what evolves is their neural network brain that make decisions on how to move the creature and get it to a safe zone by the end of the sim.
